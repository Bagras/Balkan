# Балканский протекторат

Текстовая стратегия о международной администрации в вымышленной балканской
стране. Игрок — Верховный представитель, назначенный ООН на 30 ходов. Правильных
вариантов нет: у каждого решения есть цена, и моральный выбор обычно дороже.

Движок — Godot 4.3, весь текст на русском.

## Запуск

Открыть папку проекта в Godot 4.3 и нажать F5. Главная сцена — `scenes/main.tscn`.

## Проверки

```bash
godot --headless --path . --script res://tests/run_tests.gd   # 58 тестов ядра
godot --headless --path . --script res://tests/ui_smoke.gd    # прогон партии по кнопкам
godot --headless --path . --script res://tools/simulate.gd -- 500  # баланс
```

Симулятор прогоняет партии четырьмя стратегиями-ботами и печатает распределение
концовок, долю поражений и средние итоговые шкалы. Это основной инструмент
балансировки: после правки чисел сначала смотрим на его вывод.

## Где что лежит

| Путь | Что это |
|---|---|
| `docs/DESIGN.md` | дизайн-документ: шкалы, ход, кризисы, патроны, концовки |
| `content/*.json` | весь контент игры |
| `scripts/core/` | ядро: не знает про интерфейс, проверяется headless |
| `scripts/ui/` | интерфейс, целиком собирается кодом |
| `tools/parse_docx.py` | генератор `content/events.json` из исходного `.docx` |

## Как править контент

**Текст 47 событий из `.docx` руками не правится.** Он генерируется:

```bash
python3 tools/parse_docx.py путь/к/ивентам.docx content/events.json
```

Парсер разбирает не только текст, но и служебную разметку: эффекты в фигурных
скобках, условия доступности и заметки вида «Через 6–9 ходов — Т-1» —
последние превращаются в исполняемые хуки, а не остаются комментарием.

Всё остальное (`config.json`, `actions.json`, `crises.json`, `patrons.json`,
`endings.json`) правится напрямую.

### Главная ручка баланса

`effect_multiplier` в `content/config.json`. Авторская амплитуда эффектов
(±1…8) слишком мала для шкалы 0…100 — при множителе 1.0 партию невозможно ни
проиграть, ни выиграть по-настоящему. Сейчас 2.0. Меняется одним числом, после
чего прогоняется симулятор.
